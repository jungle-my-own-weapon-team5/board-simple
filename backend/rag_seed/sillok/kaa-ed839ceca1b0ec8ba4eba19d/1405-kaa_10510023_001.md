# 최운해와 이귀철을 경상도와 충청도의 도절제사로 임명하다

- 출전: 태조실록10권, 태조 5년 10월 23일 정미 1/2 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10510023_001
- URL: https://sillok.history.go.kr/id/kaa_10510023_001
- 분류: 인사-임면(任免)

## 국역

지중추원사 최운해(崔雲海)로 경상도 병마 도절제사를 삼고, 전 이성 병마사(泥城兵馬使) 이귀철(李龜鐵)로 충청도 병마 도절제사를 삼았다.
