# 서운관 관원에게 산이 무너지면 운세가 어떠한지를 묻다

## 국역

임금이 서운관(書雲觀) 관원을 불러서 묻기를,

"산이 무너지는 것은 어떠냐?"

하니, 대답하기를,

"명산(名山)이 아니라면 해가 없습니다."

하였다.
