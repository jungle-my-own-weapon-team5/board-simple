# 왜선 2척을 포획한 수군 만호 차준에게 술을 하사하다

- 출전: 태조실록5권, 태조 3년 2월 26일 병신 3/4 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10302026_003
- URL: https://sillok.history.go.kr/id/kaa_10302026_003
- 분류: 외교-왜(倭) / 왕실-사급(賜給)

## 국역

경상도 도절제사(都節制使)가 보고하였다.

"수군 만호(水軍萬戶) 차준(車俊)이 왜선(倭船) 2척을 잡았습니다."

사자(使者)를 보내어 술을 내려 주었다.
