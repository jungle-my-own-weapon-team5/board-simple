# 도당에서 각도 역마의 짐 무게를 60근으로 제한하다

- 출전: 태조실록10권, 태조 5년 11월 21일 을해 2/2 기사 / 1396년 명 홍무(洪武) 29년

- URL: https://sillok.history.go.kr/id/kaa_10511021_002

## 국역

도당(都堂)에서 각도 역마(驛馬)의 짐 싣는 것을 60근을 한도로 하고, 무게를 안 후 지나다니게 하였다.
