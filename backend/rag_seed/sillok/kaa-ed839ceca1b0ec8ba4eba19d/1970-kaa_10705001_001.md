# 흥천사 북쪽에 사리전을 건축하도록 명하다

- 출전: 태조실록14권, 태조 7년 5월 1일 정미 1/1 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10705001_001
- URL: https://sillok.history.go.kr/id/kaa_10705001_001
- 분류: 왕실-행행(行幸) / 사상-불교(佛敎) / 건설-건축(建築) / 재정-역(役)

## 국역

임금이 흥천사(興天寺)에 가서 사리전(舍利殿) 3층을 흥천사의 북쪽에 건축하도록 명령하고, 각영(各領)의 대장(隊長)과 대부(隊副)로 자원하는 사람 50명을 모집하여 식량을 주어 부역(賦役)에 나오게 하였다.
