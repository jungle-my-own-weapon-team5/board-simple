# 천둥 번개가 치고 우박이 내리며 무지개가 나타나다. 화성이 헌원성을 범하다

- URL: https://sillok.history.go.kr/id/kaa_10708023_001

## 국역

천둥과 번개가 치고 우박이 내리며 무지재가 곤방(坤方)에 나타났다. 화성(火星)이 헌원성(軒轅星)의 왼쪽 모퉁이를 범하였다.
