# 왜선 1척을 섬멸한 전라도 수군 첨절제사 김빈길에게 물품을 하사하다

- 출전: 태조실록5권, 태조 3년 3월 23일 임술 1/1 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10303023_001
- URL: https://sillok.history.go.kr/id/kaa_10303023_001
- 분류: 외교-왜(倭) / 왕실-사급(賜給)

## 국역

전라도 수군 첨절제사가 김빈길(金贇吉)이 왜적의 배 1척을 잡아 병기(兵器)를 거두어 바치니, 임금이 사자(使者)를 보내어 궁온(宮醞)과 무늬 있는 비단과 명주를 내려 주었다.
