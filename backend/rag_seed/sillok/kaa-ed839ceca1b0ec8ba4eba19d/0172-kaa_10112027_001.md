# 대장군 오몽을이 완산 자제 26명을 데리고 오니 술을 내리다

- 출전: 태조실록2권, 태조 1년 12월 27일 계유 1/2 기사 / 1392년 명 홍무(洪武) 25년
- 기사 ID: kaa_10112027_001
- URL: https://sillok.history.go.kr/id/kaa_10112027_001

## 국역

대장군 오몽을(吳蒙乙)이 완산(完山)의 자제(子弟) 26인을 거느리고 오니, 임금이 불러 내전(內殿)에 들어오게 하여 술을 내리고, 의안백(義安伯) 이화(李和)로 하여금 이들을 관장하게 하였다.
