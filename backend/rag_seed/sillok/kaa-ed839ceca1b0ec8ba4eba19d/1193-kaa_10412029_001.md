# 백악을 진국백, 남산을 목멱대왕으로 삼아 일반인의 제사를 금하다

- 출전: 태조실록8권, 태조 4년 12월 29일 무오 1/1 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10412029_001
- URL: https://sillok.history.go.kr/id/kaa_10412029_001
- 분류: 사상-토속신앙(土俗信仰) / 사법-법제(法制)

## 국역

이조에 명하여 백악(白岳)을 진국백(鎭國伯)으로 삼고 남산(南山)을 목멱대왕(木覓大王)으로 삼아, 경대부(卿大夫)와 사서인(士庶人)은 제사를 올릴 수 없게 하였다.
