# 양가 도승통 상부가 중이 술마시는 것을 금할 것을 청하다

- 출전: 태조실록13권, 태조 7년 4월 11일 정해 2/2 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10704011_002
- URL: https://sillok.history.go.kr/id/kaa_10704011_002
- 분류: 사상-불교(佛敎) / 사법-법제(法制)

## 국역

양가 도승통(兩街都僧統) 상부(尙孚)가 중[僧]이 술 마시는 것을 금할 것을 청하니, 임금이 헌사(憲司)로 하여금 엄히 금(禁)하게 하고, 이를 범(犯)하는 자는 머리를 길러 충군(充軍)하게 하였다.
