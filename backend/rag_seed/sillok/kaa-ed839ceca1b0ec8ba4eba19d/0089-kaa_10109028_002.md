# 개국 공신의 자손들이 충효계를 맺고 왕륜동에서 회맹하다

- 출전: 태조실록2권, 태조 1년 9월 28일 병오 2/2 기사 / 1392년 명 홍무(洪武) 25년
- 기사 ID: kaa_10109028_002
- URL: https://sillok.history.go.kr/id/kaa_10109028_002
- 분류: 인사-관리(管理) / 향촌-계(契)

## 국역

개국 공신(開國功臣)의 자손과 동생과 사위들이 충효계(忠孝契)를 맺고 왕륜동에서 회맹(會盟)하였다.
