# 조준이 질병이 있는 조관에게 의원을 보내 진찰하는 제도를 실시하자고 청하다

- 출전: 태조실록4권, 태조 2년 11월 28일 기사 2/4 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10211028_002
- URL: https://sillok.history.go.kr/id/kaa_10211028_002

## 국역

좌시중(左侍中) 조준(趙浚)이 조관(朝官)의 질병에 의원을 보내어 진찰하는 법을 시행하기를 청하였다.
