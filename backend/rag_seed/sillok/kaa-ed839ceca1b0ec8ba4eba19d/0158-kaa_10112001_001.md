# 동북면 8개 능의 제사를 사맹월과 납일에는 종실이, 명절에는 도순문사가 지내도록 하다

- 출전: 태조실록2권, 태조 1년 12월 1일 정미 1/2 기사 / 1392년 명 홍무(洪武) 25년
- 기사 ID: kaa_10112001_001
- URL: https://sillok.history.go.kr/id/kaa_10112001_001
- 분류: 왕실-종사(宗社) / 왕실-의식(儀式)

## 국역

임금이 교지를 내렸다.

"동북면(東北面)의 8능(陵)에 사맹월(四孟月)과 납일(臘日)에는 특별히 종실(宗室)과 대신을 보내어 제사를 지내게 하고, 삭망(朔望)과 시속의 명절에는 도순문사(都巡問使)로 하여금 제사를 지내게 하라."
