# 피비가 영평 백운산에 내리니 소재 법석을 베풀게 하다

- 출전: 태조실록14권, 태조 7년 6월 19일 계해 1/1 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10706019_001
- URL: https://sillok.history.go.kr/id/kaa_10706019_001
- 분류: 과학-천기(天氣) / 사상-토속신앙(土俗信仰)

## 국역

피비가 영평(永平)의 백운산(白雲山)에 내리니, 영성군(寧城君) 오사충(吳思忠)을 보내어 법석(法席)을 베풀고 재앙을 물리치게 하였다.
