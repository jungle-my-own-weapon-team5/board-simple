# 판예빈시사 김정경을 전라·충청도에 보내어 수군 현황을 조사하다

- 출전: 태조실록9권, 태조 5년 6월 1일 정해 3/3 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10506001_003
- URL: https://sillok.history.go.kr/id/kaa_10506001_003
- 분류: 인사-임면(任免) / 군사-군기(軍器)

## 국역

판예빈시사 김정경(金定卿)을 전라·충청도에 보내어 공전(攻戰) 연습을 감독하고, 병선(兵船)의 허실을 조사하게 하며, 또 빼앗긴 전함과 죽은 사람의 수를 기록하게 하였다.
