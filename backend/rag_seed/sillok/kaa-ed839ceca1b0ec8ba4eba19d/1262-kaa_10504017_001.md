# 유후사의 박연, 임진현의 덕진, 개성현의 대정 등지에 내시를 보내어 비를 빌게 하다

- 출전: 태조실록9권, 태조 5년 4월 17일 갑진 1/3 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10504017_001
- URL: https://sillok.history.go.kr/id/kaa_10504017_001
- 분류: 사상-토속신앙(土俗信仰) / 사상-불교(佛敎)

## 국역

내시(內侍)를 유후사의 박연(朴淵)과, 임진현(臨津縣)의 덕진(德津)과, 개성현(開城縣)의 대정(大井)과 해풍군(海豐郡)의 남진(南津)과, 연안부(延安府)의 대지(大池)에 나누어 보내어 제사지내고, 포주(抱州)006) 해룡왕사(海龍王寺)와 강음(江陰)007) 천신사(天神寺)에도 재를 올려 비를 빌게 하였다.
