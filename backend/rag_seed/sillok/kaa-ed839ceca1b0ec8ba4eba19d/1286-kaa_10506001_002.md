# 중국에 구류당해 있는 사신들을 봉군(封君)하다

- 출전: 태조실록9권, 태조 5년 6월 1일 정해 2/3 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10506001_002
- URL: https://sillok.history.go.kr/id/kaa_10506001_002
- 분류: 인사-임면(任免) / 인사-관리(管理)

## 국역

중국에서 구류당하고 있는 유구(柳玽)로 진천군(晉川君)을 봉하고, 정총(鄭摠)으로 서원군(西原君)을 봉하고, 정신의(鄭臣義)로 오천군(烏川君)을 봉하고, 김약항(金若恒)으로 광산군(光山君)을 봉하였다. 우도 도관찰사 홍길민(洪吉旼)이 부친상을 당하여, 박경(朴經)을 대신 〈관찰사로〉 임명하였다.
