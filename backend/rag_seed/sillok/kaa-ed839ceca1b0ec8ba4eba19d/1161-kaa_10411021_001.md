# 각도의 수령을 비롯한 여러 관원들의 잘잘못을 상세히 보고케 하다

- 출전: 태조실록8권, 태조 4년 11월 21일 신사 1/1 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10411021_001
- URL: https://sillok.history.go.kr/id/kaa_10411021_001
- 분류: 행정-지방행정(地方行政) / 인사-관리(管理)

## 국역

도평의사사에서 왕지(王旨)를 받들어 각도에 이첩(移牒)하였다.

"대소의 수령과 수륙 군관(水陸軍官)과 만호·천호와 유의 교수(儒醫敎授), 염철장(鹽鐵場) 관원, 역승(驛丞)의 잘잘못을 일일이 상세히 보고하라."
