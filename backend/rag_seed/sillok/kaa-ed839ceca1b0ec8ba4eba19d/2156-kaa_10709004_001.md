# 김사행과 함께 궁궐 수리로 백성들을 괴롭혔다 하여 김주를 영주로 귀양보내다

- 출전: 태조실록15권, 태조 7년 9월 4일 병자 1/1 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10709004_001
- URL: https://sillok.history.go.kr/id/kaa_10709004_001
- 분류: 사법-행형(行刑) / 건설-건축(建築)

## 국역

상의문하부사(商議門下府事) 김주(金湊)를 영주(寧州)로 귀양보내었다. 김주가 일찍이 김사행(金師幸)과 더불어 같이 영선(營繕)을 맡아 극도로 정교하기만을 힘써서 백성의 힘을 괴롭게 했기 때문이었다.
