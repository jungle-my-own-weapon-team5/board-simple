# 하윤과 조박에게 《사서》에 구두점을 쳐서 바치게 하다

- 출전: 태조실록15권, 태조 7년 9월 17일 기축 1/2 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10709017_001
- URL: https://sillok.history.go.kr/id/kaa_10709017_001
- 분류: 왕실-국왕(國王)

## 국역

지경연사 정당 문학(知經筵事政堂文學) 하윤(河崙)과 겸 대사헌(兼大司憲) 조박(趙璞)에게 명하였다.

"내가 《사서(四書)》를 보고자 하니 구절(句節)마다 점(點)을 쳐서 바치라."
