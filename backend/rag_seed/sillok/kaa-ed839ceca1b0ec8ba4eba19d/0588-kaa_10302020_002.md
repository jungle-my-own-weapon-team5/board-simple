# 왜적 13명을 죽인 경상도 수군 만호 차준에게 물품을 하사하다

- 출전: 태조실록5권, 태조 3년 2월 20일 경인 2/3 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10302020_002
- URL: https://sillok.history.go.kr/id/kaa_10302020_002
- 분류: 외교-왜(倭) / 왕실-사급(賜給)

## 국역

경상도 수군 만호(水軍萬戶) 차준(車俊)이 왜적(倭賊)의 배 1척을 잡아서 머리 13급(級)을 베고 노획한 병기까지 합하여 바치니, 명하여 궁온(宮醞)과 무늬 있는 비단과 명주를 내려 주었다.
