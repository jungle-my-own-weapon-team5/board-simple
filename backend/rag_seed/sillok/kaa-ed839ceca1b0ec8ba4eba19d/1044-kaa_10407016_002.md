# 내신을 회암사에 보내어 왕사에게 문안하다

- 출전: 태조실록8권, 태조 4년 7월 16일 정미 2/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10407016_002
- URL: https://sillok.history.go.kr/id/kaa_10407016_002
- 분류: 왕실-사급(賜給) / 왕실-의식(儀式) / 사상-불교(佛敎)

## 국역

내신(內臣)을 회암사(檜巖寺)에 보내어 왕사(王師)에게 문안드리게 하고, 인하여 저포(苧布)·마포(麻布)를 하사하였다.
