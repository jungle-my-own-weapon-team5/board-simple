# 판의흥삼군부사 정도전과 장수들이 쇠 갑옷을 입고 둑에 제사지내다

- 출전: 태조실록5권, 태조 3년 1월 27일 정묘 1/1 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10301027_001
- URL: https://sillok.history.go.kr/id/kaa_10301027_001
- 분류: 왕실-의식(儀式) /

## 국역

판의흥삼군부사(判義興三軍府事) 정도전(鄭道傳)을 보내어 태뢰(太牢)006) 로써 둑(纛)에 제사지내게 하니, 도전(道傳)과 제사에 참여한 장사(將士)들이 모두 철갑(鐵甲) 차림으로 제사를 지냈다. 제사를 마치고 난 뒤에 천호(千戶) 유서봉(兪瑞鳳)이 갑자기 죽었다.
