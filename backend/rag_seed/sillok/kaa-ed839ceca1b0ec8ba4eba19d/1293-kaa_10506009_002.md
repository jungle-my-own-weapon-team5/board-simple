# 유원정의 종 2인을 무고죄로 치죄하다

- 출전: 태조실록9권, 태조 5년 6월 9일 을미 2/2 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10506009_002
- URL: https://sillok.history.go.kr/id/kaa_10506009_002
- 분류: 사법-법제(法制) / 사법-행형(行刑)

## 국역

형조에서 유원정(柳爰廷)의 종[奴] 2인을 무고(誣告)로 논죄하여 각각 장(杖) 1백 대와 도(徒) 3년에 처하였다.
