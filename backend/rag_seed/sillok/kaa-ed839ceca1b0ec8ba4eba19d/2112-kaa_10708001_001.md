# 여러 왕자와 남은·이무·상장군 등이 《진도》를 익히지 않은 까닭을 묻다

- 출전: 태조실록14권, 태조 7년 8월 1일 갑진 1/1 기사 / 1398년 명 홍무(洪武) 31년

- URL: https://sillok.history.go.kr/id/kaa_10708001_001
- 분류: 군사-병법(兵法)

## 국역

사헌부에 명하여 여러 왕자와 의성군(宜城君) 남은, 참찬문하부사(參贊門下府事) 이무(李茂), 상장군·대장군 등이 《진도(陣圖)》를 익히지 않는 까닭을 묻게 하였다.
