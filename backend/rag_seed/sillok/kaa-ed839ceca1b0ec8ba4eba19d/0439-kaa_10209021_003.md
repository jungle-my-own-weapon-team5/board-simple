# 유경·이거이·정탁·박신·김승 등에게 관직을 제수하다

- 출전: 태조실록4권, 태조 2년 9월 21일 계해 3/3 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10209021_003
- URL: https://sillok.history.go.kr/id/kaa_10209021_003
- 분류: 인사-임면(任免)

## 국역

유경(劉敬)을 좌산기 상시(左散騎常侍)로, 이거이(李居易)를 우산기 상시(右散騎常侍)로, 정탁(鄭擢)을 직문하(直門下)로, 박신(朴信)을 겸 사헌 중승(兼司憲中丞)으로, 김승(金陞)을 사헌 중승(司憲中丞)으로 삼았다.
