# 중추원의 8인에게 서북면의 수령을 겸하게 하다

- 출전: 태조실록9권, 태조 5년 3월 7일 갑자 1/1 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10503007_001
- URL: https://sillok.history.go.kr/id/kaa_10503007_001
- 분류: 인사-임면(任免)

## 국역

중추원(中樞院)의 8인으로 하여금 서북면의 수령을 겸하게 하였는데, 김로(金輅)는 이성(泥城)에, 임경(林敬)은 강계(江界)에, 조숭(趙崇)은 의주(義州)에, 박포(朴苞)는 황주(黃州)에, 장담(張湛)은 정주(定州)에, 황거정(黃居正)은 숙주(肅州)에, 남실(南實)은 성주(成州)002) 에, 오몽을(吳蒙乙)은 연산부(延山府)003) 에 보냈다.
