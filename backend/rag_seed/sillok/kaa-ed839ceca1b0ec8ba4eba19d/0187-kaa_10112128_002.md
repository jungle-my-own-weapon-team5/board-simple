# 유구국 중산왕이 신하라고 칭하면서 예물을 바치고, 포로 8명을 송환하다

- 출전: 태조실록2권, 태조 1년 윤12월 28일 갑진 2/2 기사 / 1392년 명 홍무(洪武) 25년
- 기사 ID: kaa_10112128_002
- URL: https://sillok.history.go.kr/id/kaa_10112128_002
- 분류: 외교-유구(琉球)

## 국역

이 해에 유구국(琉球國)의 중산왕(中山王) 찰도(察度)가 신하로 일컫고 글을 받들어 통사(通事) 이선(李善) 등을 보내어 예물(禮物)을 가져와서 바치고, 아울러 사로잡혔던 남녀 8명을 송환(送還)하였다.
