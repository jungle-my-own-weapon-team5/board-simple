# 서북면 도순문사 조온에게 의주도의 군적을 고쳐서 정리하도록 명하다

- 출전: 태조실록4권, 태조 2년 7월 2일 을사 2/2 기사 / 1393년 명 홍무(洪武) 26년

- URL: https://sillok.history.go.kr/id/kaa_10207002_002

## 국역

서북면(西北面) 도순문사(都巡問使) 조온(趙溫)에게 명하여 의주도(義州道)의 군적(軍籍)을 고쳐 마련(磨鍊)하게 하였다.
