# 홍경천에서 사냥하다. 윤침의 가노 2인이 의성고의 소속으로 해줄 것을 하소하다

- 출전: 태조실록9권, 태조 5년 3월 13일 경오 1/1 기사 / 1396년 명 홍무(洪武) 29년

- URL: https://sillok.history.go.kr/id/kaa_10503013_001

## 국역

임금이 홍경천(弘慶川)004) 북교(北郊)에서 사냥을 하는데, 윤침(尹忱)의 집종[家奴] 2인이 의성고(義成庫) 종으로 소속되려고 임금의 행차 앞에 나아와 하소연하매, 명하여 곤장을 쳐서 보내게 하였다.
