# 진안군의 관을 작게 만든 선공감의 관원을 순군옥에 가두었다가 석방하다

- 출전: 태조실록4권, 태조 2년 12월 21일 임진 1/1 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10212021_001
- URL: https://sillok.history.go.kr/id/kaa_10212021_001
- 분류: 사법-행형(行刑) /

## 국역

선공감(繕工監)의 관리를 순군옥(巡軍獄)에 가두다. 선공감(繕工監)에서 진안군(鎭安君)의 곽(槨)을 만들었는데, 좁고 작아서 관(棺)을 능히 용납하지 못하게 한 때문이다. 23일에 이를 석방하였다.
