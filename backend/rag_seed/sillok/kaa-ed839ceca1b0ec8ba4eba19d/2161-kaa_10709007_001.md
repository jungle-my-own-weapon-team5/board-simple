# 붉은 기운이 있었다. 상왕이 이방석 등을 위하여 소선을 들다

- 출전: 태조실록15권, 태조 7년 9월 7일 기묘 1/3 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10709007_001
- URL: https://sillok.history.go.kr/id/kaa_10709007_001
- 분류: 왕실-국왕(國王) / 과학-천기(天氣)

## 국역

붉은 기운이 있었다. 상왕(上王)이 이방석(李芳碩) 등을 위하여 소선(素膳)을 드니, 도평의사사(都評議使司)에서 육선(肉膳)을 올리기를 청하였다.
