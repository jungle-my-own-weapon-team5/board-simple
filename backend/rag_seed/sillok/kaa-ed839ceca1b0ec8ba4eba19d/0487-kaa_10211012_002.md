# 정도전이 군사를 집합시켜 《진도》 대로 훈련시키다

- 출전: 태조실록4권, 태조 2년 11월 12일 계축 2/4 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10211012_002
- URL: https://sillok.history.go.kr/id/kaa_10211012_002
- 분류: 군사-병법(兵法)

## 국역

정도전이 군사를 구정(毬庭)에 모아 진도(陣圖)를 설치하고서, 그들로 하여금 고각(鼓角)·기휘(旗麾)·좌작 진퇴(坐作進退)의 절차를 익히게 하였다.
