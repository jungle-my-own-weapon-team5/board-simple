# 서북면 도순문찰리사 최영지에게 교서와 부월, 궁온을 내려 주다

- 출전: 태조실록13권, 태조 7년 1월 17일 을축 2/2 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10701017_002
- URL: https://sillok.history.go.kr/id/kaa_10701017_002
- 분류: 왕실-사급(賜給)

## 국역

임금이 전 사수감(司水監) 박유손(朴有孫)을 보내어 서북면 도순문찰리사(都巡問察理使) 최영지(崔永沚)에게 교서(敎書)와 부월(鈇鉞)을 내려 주고, 인하여 궁온(宮醞)을 내려 주었다.
