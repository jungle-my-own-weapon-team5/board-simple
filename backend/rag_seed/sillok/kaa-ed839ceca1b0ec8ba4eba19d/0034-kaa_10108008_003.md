# 개성 소윤 함부림을 경상도 등에 보내 수령의 업무를 고과하도록 하다

- 출전: 태조실록1권, 태조 1년 8월 8일 정사 3/4 기사 / 1392년 명 홍무(洪武) 25년

## 국역

개성 소윤(開城少尹) 함부림(咸傅霖)을 경상·전라·양광도(楊廣道)에 보내어 수령(守令)의 유능하고 유능하지 못한 것과 민간(民間)의 기쁘고 근심되는 것을 살피게 하였다.
