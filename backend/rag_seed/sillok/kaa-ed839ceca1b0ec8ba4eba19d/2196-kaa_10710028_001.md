# 원망을 품고 조준을 무고한 조준의 첩 국화를 한강에 침장하다

- 출전: 태조실록15권, 태조 7년 10월 28일 경오 1/1 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10710028_001
- URL: https://sillok.history.go.kr/id/kaa_10710028_001
- 분류: 사법-행형(行刑) / 사법-치안(治安) /

## 국역

순군부(巡軍府)에서 기생 국화(菊花)를 한강(漢江)에 침장(沈葬)하였다. 처음에 국화가 조준의 첩이 되었었는데, 버림을 당하여 원망을 품어 다른 사람에게 말하기를,

"조준이 반역할 뜻이 있습니다."

하였다. 이에 조준이 그를 국문(鞫問)하기를 청하니, 명하여 순군부에 국화를 가두어 공초(供招)를 받고 마침내 한강에 침장(沈葬)하게 하였다.
