# 임금의 초상을 계림부에 봉안하다

- 출전: 태조실록13권, 태조 7년 3월 6일 계축 3/3 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10703006_003
- URL: https://sillok.history.go.kr/id/kaa_10703006_003
- 분류: 왕실-종사(宗社) /

## 국역

판삼사사(判三司事) 설장수(偰長壽)를 보내어 임금의 진영(眞影)을 계림부(鷄林府)에 봉안(奉安)하였다. 임금이 유후사(留後司)에서 형조 전서(刑曹典書) 이귀령(李貴齡) 등에게 명하여 일을 보게 하였다.
