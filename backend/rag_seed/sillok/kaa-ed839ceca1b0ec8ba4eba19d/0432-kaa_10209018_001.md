# 수창궁에서 성절을 하례하고 시좌소로 돌아오다

- 출전: 태조실록4권, 태조 2년 9월 18일 경신 1/3 기사 / 1393년 명 홍무(洪武) 26년

- URL: https://sillok.history.go.kr/id/kaa_10209018_001
- 분류: 외교-명(明) / 왕실-의식(儀式)

## 국역

임금이 여러 신하를 거느리고 성절(聖節)을 수창궁에서 하례하고는 시좌소(時坐所)로 돌아왔다.
