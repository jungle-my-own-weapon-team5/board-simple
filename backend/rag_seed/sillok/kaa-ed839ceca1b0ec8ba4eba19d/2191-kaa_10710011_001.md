# 상왕의 탄신일이라 여러 종친과 함께 연향을 베풀고 이죄 이하를 사유하다

- 출전: 태조실록15권, 태조 7년 10월 11일 계축 1/1 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10710011_001
- URL: https://sillok.history.go.kr/id/kaa_10710011_001

## 국역

상왕(上王)의 탄신일(誕辰日)이었다. 병이 이때에 이르러 회복되니, 임금이 여러 종친과 공후(公侯)를 거느리고 북량청(北涼廳)에서 연향(宴享)하여 한껏 즐기고 파하였다. 이죄(二罪) 이하의 죄수를 용서하였다.
