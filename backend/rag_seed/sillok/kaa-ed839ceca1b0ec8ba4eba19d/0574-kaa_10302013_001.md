# 경상도 수군 첨절제사 안처선이 왜적 12명을 죽이니 궁온 등을 하사하다

- 출전: 태조실록5권, 태조 3년 2월 13일 계미 1/1 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10302013_001
- URL: https://sillok.history.go.kr/id/kaa_10302013_001
- 분류: 외교-왜(倭) / 왕실-사급(賜給)

## 국역

경상도 수군 첨절제사(水軍僉節制使) 안처선(安處善)이 왜적(倭賊) 12명을 목 베고, 노획한 병기(兵器)까지 모두 바치니, 임금이 명하여 궁온(宮醞)014) 과 무늬 있는 비단[綺]과 명주[絹]를 내려 주었다.
