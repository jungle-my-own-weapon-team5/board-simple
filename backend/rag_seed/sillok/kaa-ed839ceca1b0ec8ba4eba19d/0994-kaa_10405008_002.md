# 백백 태자와 양왕의 손자에게 쌀과 콩 등을 내려 주다

- 출전: 태조실록7권, 태조 4년 5월 8일 경자 2/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10405008_002
- URL: https://sillok.history.go.kr/id/kaa_10405008_002
- 분류: 왕실-사급(賜給) /

## 국역

백백 태자(伯伯太子)에게 쌀과 콩 4백 곡(斛)과 저포(紵布)·마포(麻布) 30필을 내려 주고, 양왕(梁王)의 손자에게 쌀과 콩 1백 곡과 저포·마포 10필을 내려 주었다.
