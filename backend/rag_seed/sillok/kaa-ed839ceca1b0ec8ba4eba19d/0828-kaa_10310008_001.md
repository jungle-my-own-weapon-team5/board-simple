# 채단 옷을 입은 이지숭을 파면시키고 김천구를 순군옥에 가두다

- 출전: 태조실록6권, 태조 3년 10월 8일 갑술 1/1 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10310008_001
- URL: https://sillok.history.go.kr/id/kaa_10310008_001
- 분류: 인사-임면(任免) / 인사-관리(管理) / 사법-행형(行刑) /

## 국역

장군 이지숭(李之崇)의 벼슬을 파면하고, 전 전서(典書) 김천구(金千具)를 순군(巡軍)에 가두었다. 이는 사헌부에서 채단 옷을 입었다고 탄핵한 까닭이었다.
