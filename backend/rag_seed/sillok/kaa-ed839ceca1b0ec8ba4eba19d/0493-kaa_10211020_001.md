# 얼음이 얼지 않는 등의 기후 변화로 소격전에서 초제를 지내다

- 출전: 태조실록4권, 태조 2년 11월 20일 신유 1/1 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10211020_001
- URL: https://sillok.history.go.kr/id/kaa_10211020_001
- 분류: 과학-천기(天氣) / 사상-도교(道敎)

## 국역

얼음이 얼지 아니하고 또 안개가 끼인 이유로써, 좌승지 최이(崔迤)를 보내어 소격전(昭格殿)에서 태일성(太一星)을 초제(醮祭)하여 절후(節候)가 조화(調和)되기를 빌게 하였다.
