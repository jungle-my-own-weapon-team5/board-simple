# 수로 전운소 완호 별감을 두다

- 출전: 태조실록7권, 태조 4년 1월 11일 병오 1/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10401011_001
- URL: https://sillok.history.go.kr/id/kaa_10401011_001
- 분류: 행정-지방행정(地方行政) / 교통-수운(水運)

## 국역

수로 전운소 완호 별감(水路轉運所完護別監)을 두었다. 용산강(龍山江)으로부터 충주(忠州)의 연천(淵遷)까지 무릇 일곱 소(所)에 각각 30호씩 예속시키었다.
