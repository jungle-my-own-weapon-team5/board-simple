# 대간과 육조에게 현량을 천거토록 하다

## 국역

명하여 현량(賢良)을, 대간(臺諫)과 육조(六曹)의 1원(員)마다 각기 산관(散官) 4품 이하와 6품 이상의 3인씩을 천거하게 하였다.
