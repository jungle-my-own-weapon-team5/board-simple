# 민간에서 흰 가축을 기르지 못하게 한다는 말을 퍼뜨린 능귀 등을 참형하다

## 국역

수원(水原) 기관(記官) 능귀(能貴)와 용구(龍駒)001) 호장(戶長) 희진(希進)이 요망한 말을 만들어,

"민간에서 흰 빛깔의 개·말·닭·염소 등을 기르지 못하게 한다."

하였으므로, 모두 참형에 처하여 여러 도에 전해 보이었다.
