# 유성이 천시원 동쪽에서 나와 서쪽으로 들어가다

- 출전: 태조실록11권, 태조 6년 2월 25일 무신 2/2 기사 / 1397년 명 홍무(洪武) 30년
- 기사 ID: kaa_10602025_002
- URL: https://sillok.history.go.kr/id/kaa_10602025_002
- 분류: 과학-천기(天氣)

## 국역

흐르는 별이 천시 동원(天市東垣)에서 나와 서원(西垣)으로 들어갔는데, 길이가 2척쯤 되었다.
