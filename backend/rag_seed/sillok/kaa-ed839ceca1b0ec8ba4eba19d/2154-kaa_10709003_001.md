# 한간이 수정포도를 바치다. 왕의 병이 이로부터 회복되다

- 출전: 태조실록15권, 태조 7년 9월 3일 을해 1/2 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10709003_001
- URL: https://sillok.history.go.kr/id/kaa_10709003_001
- 분류: 왕실-국왕(國王) / 왕실-사급(賜給) / 재정-진상(進上)

## 국역

한간(韓幹)이 수정포도(水精葡萄)를 구하여 와서 바치므로, 임금이 매우 기뻐하여 쌀 10석을 내려 주었다. 임금이 매양 목이 마를 적엔 한두 개를 맛보니, 병이 이로부터 회복되었다.
