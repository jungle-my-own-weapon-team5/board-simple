# 장사길과 곽충보에게 문화현 등지에 침입한 왜구를 공격토록 하다

- 출전: 태조실록3권, 태조 2년 6월 6일 경진 2/2 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10206006_002
- URL: https://sillok.history.go.kr/id/kaa_10206006_002
- 분류: 외교-왜(倭)

## 국역

왜적(倭賊)이 문화현(文化縣)·영녕현(永寧縣)의 두 현(縣)에 침구하니, 영안군(永安君)과 동지중추원사(同知中樞院事) 장사길(張思吉)과 상의중추원사(商議中樞院事) 곽충보(郭忠輔)를 보내어 이를 치게 하였다.
