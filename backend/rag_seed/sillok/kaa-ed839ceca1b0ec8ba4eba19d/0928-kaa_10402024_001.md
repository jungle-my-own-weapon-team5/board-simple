# 천변 때문에 죄수를 석방하고, 감옥의 청결 상태를 점검하도록 명하다

- 출전: 태조실록7권, 태조 4년 2월 24일 무자 1/3 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10402024_001
- URL: https://sillok.history.go.kr/id/kaa_10402024_001
- 분류: 사법-행형(行刑) / 과학-천기(天氣)

## 국역

중외(中外)의 이죄(二罪) 이하의 죄수를 다 석방하였으니, 천변(天變) 때문이었다. 도평의사사(都評議使司)에 명령하였다.

"서울과 지방의 감옥이 더럽고 수리하지 아니하여, 무더위와 모진 추위에 병이 들어 비명에 죽게 되니, 내 심히 민망히 여긴다. 그 곳 관리로 하여금 때때로 돌아보고 깨끗하게 하도록 하라."
