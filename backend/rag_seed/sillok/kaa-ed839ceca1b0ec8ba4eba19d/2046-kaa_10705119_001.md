# 옛 과주의 아록 인리전 135결을 유비고에 소속시키다

- 출전: 태조실록14권, 태조 7년 윤5월 19일 갑오 1/1 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10705119_001
- URL: https://sillok.history.go.kr/id/kaa_10705119_001
- 분류: 재정-창고(倉庫) / 농업-전제(田制) / 신분-천인(賤人)

## 국역

옛 과주(果州) 아록 인리(衙祿人吏)의 전지 1백 35결(結)을 유비고(有備庫)에 소속시키고, 그 고노(庫奴)로 하여금 전지를 경작하게 하였다.
