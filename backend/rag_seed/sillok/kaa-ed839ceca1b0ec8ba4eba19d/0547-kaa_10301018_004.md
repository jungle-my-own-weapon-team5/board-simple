# 도당에서 공사 어량과 염분을 사재감에, 둔수군의 둔전 번염을 군자에 충당하기를 청하다

- 출전: 태조실록5권, 태조 3년 1월 18일 무오 4/5 기사 / 1394년 명 홍무(洪武) 27년

- 분류: 재정-창고(倉庫) / 군사-병참(兵站)

## 국역

도평의사사에서 공사(公私)의 어염량(魚鹽梁)을 모두 사재감(司宰監)에 소속시키고, 둔수군(屯戍軍)의 둔전 번염(屯田燔鹽)을 회복시켜 군자(軍資)에 충당하기를 청하였다.
