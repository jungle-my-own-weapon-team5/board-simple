# 충청도 도관찰사 하윤과 경기좌도 관찰사 이정보에게 교서와 부월을 주다

- 출전: 태조실록14권, 태조 7년 8월 2일 을사 2/2 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10708002_002
- URL: https://sillok.history.go.kr/id/kaa_10708002_002
- 분류: 왕실-의식(儀式)

## 국역

임금이 서쪽 양정(涼亭)에 앉아 교서(敎書)와 부월(鈇鉞)로써 충청도 도관찰사 하윤과 경기좌도 관찰사 이정보(李廷俌)에게 친히 주었다.
