# 백관이 반열을 정돈했는데도 조회 보지 않고 흥천사에 거둥하다

- 출전: 태조실록14권, 태조 7년 6월 6일 경술 1/2 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10706006_001
- URL: https://sillok.history.go.kr/id/kaa_10706006_001
- 분류: 왕실-의식(儀式) / 왕실-국왕(國王) / 사상-불교(佛敎)

## 국역

백관(百官)들이 자리에 나아와서 반열(班列)을 정제(整齊)했는데도 임금은 조회를 보지 않고, 흥천사(興天社)에 거둥하여 사리전(舍利殿)의 건축을 시찰하였다.
