# 중추원 사 이무에게 강화의 병선을 점고하고 연해에 정박한 왜적을 잡게 하다

- 출전: 태조실록3권, 태조 2년 5월 8일 임자 2/2 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10205008_002
- URL: https://sillok.history.go.kr/id/kaa_10205008_002
- 분류: 인사-임면(任免) / 군사-군정(軍政)

## 국역

중추원 사(中樞院使) 이무(李茂)에게 명하여 강화(江華)의 병선(兵船)을 점고(點考)하고, 연해(沿海)의 요로(要路)에 정박하여 왜적(倭賊)을 잡게 하였다.
