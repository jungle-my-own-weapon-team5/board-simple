# 신덕 왕후 대상재를 흥천사에서 베풀다

- 출전: 태조실록14권, 태조 7년 8월 13일 병진 4/6 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10708013_004
- URL: https://sillok.history.go.kr/id/kaa_10708013_004
- 분류: 왕실-의식(儀式) / 사상-불교(佛敎)

## 국역

신덕 왕후(神德王后)의 대상재(大祥齋)를 흥천사(興天寺)에서 베풀었는데, 도당(都堂)에서는 흥복사(興福寺)에서 별도로 행하였다.
