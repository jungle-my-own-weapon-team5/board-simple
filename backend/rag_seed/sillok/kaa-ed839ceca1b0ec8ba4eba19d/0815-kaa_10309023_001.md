# 한양에서 정도전 등은 돌아오고, 심덕부와 김주는 남아 관리하다

- 출전: 태조실록6권, 태조 3년 9월 23일 경신 1/1 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10309023_001
- URL: https://sillok.history.go.kr/id/kaa_10309023_001
- 분류: 왕실-행행(行幸)

## 국역

판삼사사 정도전 등은 한양으로부터 돌아왔으나, 청성백(靑城伯) 심덕부(沈德符)와 참찬문하부사 김주(金湊)는 남아서 〈궁궐과 기타 도시의〉 경영을 관리하였다.
