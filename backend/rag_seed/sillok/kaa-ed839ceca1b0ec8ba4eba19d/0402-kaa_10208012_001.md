# 동북면 도안무사 이지란을 시켜 갑주와 공주에 성을 쌓게 하다

## 국역

동북면 도안무사(都安撫使) 이지란(李之蘭)을 보내어 갑주(甲州)와 공주(孔州)에 성을 쌓게 하였다.
