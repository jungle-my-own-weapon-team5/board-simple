# 이색을 한산백에 봉하고 오고 도제조로 삼다

- 출전: 태조실록8권, 태조 4년 12월 22일 신해 1/1 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10412022_001
- URL: https://sillok.history.go.kr/id/kaa_10412022_001
- 분류: 인사-임면(任免) / 인사-관리(管理)

## 국역

이색(李穡)으로 한산백(韓山伯)을 봉하고 인하여 의성고(義成庫)·덕천고(德泉庫) 등의 오고 도제조(五庫都提調)를 삼았다.
