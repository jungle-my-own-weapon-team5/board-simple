# 참찬문하부사 남은이 표찬자와 유구 등의 가속을 명나라에 보내지 말기를 청하다

- 출전: 태조실록10권, 태조 5년 7월 8일 계해 2/2 기사 / 1396년 명 홍무(洪武) 29년

## 국역

참찬문하부사(參贊門下府事) 남은(南誾)이 상서(上書)하여 찬문자(撰文者)와 유구(柳玽) 등의 가속(家屬)을 보내는 것을 정지하기를 청하였다.
