# 전라도 경상도 각 진의 첨절제사 중 《진도》에 통하지 않은 자를 매질하다

- 출전: 태조실록14권, 태조 7년 7월 27일 경자 4/5 기사 / 1398년 명 홍무(洪武) 31년

- URL: https://sillok.history.go.kr/id/kaa_10707027_004

## 국역

순군 천호(巡軍千戶) 김천익(金天益)을 전라도와 경상도의 각 진(鎭)에 보내어 첨절제사(僉節制使)로서 《진도(陣圖)》에 통하지 않은 사람을 매질하게 하였다.
