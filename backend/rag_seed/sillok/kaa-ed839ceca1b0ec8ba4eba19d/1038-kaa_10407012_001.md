# 현비가 병이 나니 중에게 기도하게 하고 죄수를 석방하다

- 출전: 태조실록8권, 태조 4년 7월 12일 계묘 1/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10407012_001
- URL: https://sillok.history.go.kr/id/kaa_10407012_001
- 분류: 사상-불교(佛敎) / 사법-행형(行刑) / 왕실-비빈(妃嬪)

## 국역

왕이 현비(顯妃)가 평안하지 못하여 중들에게 음식을 대접하고 부처에게 기도하게 하고, 중외(中外)의 이죄(二罪) 이하의 죄수는 석방하게 하였다.
