# 햇무리가 지다. 의비의 기일이므로 조회와 시장을 정지하다

- 출전: 태조실록5권, 태조 3년 2월 24일 갑오 1/1 기사 / 1394년 명 홍무(洪武) 27년

## 국역

햇무리하였다. 의비(懿妃)의 기신(忌辰)인 이유로써 임금이 감선(減膳)하고 조회와 시장(市場)을 정지하게 하였다.
