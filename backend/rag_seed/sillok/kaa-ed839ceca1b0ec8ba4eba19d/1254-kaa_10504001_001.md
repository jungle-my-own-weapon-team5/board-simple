# 거가가 온천을 떠나 영주에 머무르다

- 출전: 태조실록9권, 태조 5년 4월 1일 무자 1/1 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10504001_001
- URL: https://sillok.history.go.kr/id/kaa_10504001_001
- 분류: 왕실-행행(行幸) / 사법-법제(法制)

## 국역

거가(車駕)가 온천을 출발하여 영주(寧州)005) 에 머물렀다. 순군관(巡軍官)을 나누어 보내서 말을 놓아 보리를 해치는 것을 엄금하게 하였다.
