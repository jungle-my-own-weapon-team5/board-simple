# 참찬문하부사 안익과 동지중추원사 김희선을 하정사로 보내다

- 출전: 태조실록10권, 태조 5년 10월 3일 정해 1/1 기사 / 1396년 명 홍무(洪武) 29년

## 국역

참찬문하부사(參贊門下府事) 안익(安翊)과 동지중추원사(同知中樞院事) 김희선(金希善)을 남경에 보내어 명년 정조(正朝)를 하례하게 하였다.
