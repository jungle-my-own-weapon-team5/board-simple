# 수창궁의 서쪽 침실을 헐어 2층 전각을 건축토록 명하고, 김사행에게 감독케 하다

- 출전: 태조실록5권, 태조 3년 1월 2일 임인 1/1 기사 / 1394년 명 홍무(洪武) 27년

## 국역

명하여 수창궁의 서쪽 침실(寢室)을 헐고 2층 궁전을 건축하게 하고, 김사행(金師幸)에게 역사(役事)를 감독하도록 하였다.
