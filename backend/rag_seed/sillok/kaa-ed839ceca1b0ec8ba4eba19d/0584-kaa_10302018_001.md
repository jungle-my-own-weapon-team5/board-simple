# 수창궁에서 사신에게 잔치를 베풀고 은 등의 물품을 하사하다

- 출전: 태조실록5권, 태조 3년 2월 18일 무자 1/2 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10302018_001
- URL: https://sillok.history.go.kr/id/kaa_10302018_001
- 분류: 왕실-의식(儀式) / 왕실-사급(賜給) / 외교-명(明) /

## 국역

임금이 수창궁에 거둥하여 사신에게 잔치를 베풀고, 은(銀) 각 1정(錠), 흑마포(黑麻布)·흑저포(黑苧布) 각각 40필, 안자(鞍子) 각 1면(面)씩을 주었다.
