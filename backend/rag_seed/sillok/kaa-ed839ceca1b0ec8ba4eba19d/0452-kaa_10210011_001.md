# 임금의 탄신일이므로 이죄 이하의 죄인을 사면시키고, 중 1,500명을 공양하다

- 출전: 태조실록4권, 태조 2년 10월 11일 계미 1/1 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10210011_001
- URL: https://sillok.history.go.kr/id/kaa_10210011_001
- 분류: 왕실-의식(儀式) / 사법-행형(行刑) / 사상-불교(佛敎)

## 국역

임금의 탄생일이므로 문하부(門下府)와 각도의 관찰사·절제사들이 전문(箋文)을 올려 하례하였다. 이죄(二罪) 이하의 죄수를 사면(赦免)하고, 중[僧] 1천 5백 명을 광명사(廣明寺)에서 공양(供養)하였다.
