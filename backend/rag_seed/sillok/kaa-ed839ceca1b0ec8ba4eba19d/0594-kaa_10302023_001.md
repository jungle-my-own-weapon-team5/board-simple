# 삼성에서 왕씨 일족의 죄를 청했으나, 윤허치 않다

- 출전: 태조실록5권, 태조 3년 2월 23일 계사 1/2 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10302023_001
- URL: https://sillok.history.go.kr/id/kaa_10302023_001
- 분류: 사법-탄핵(彈劾) / 역사-전사(前史)

## 국역

대간과 형조에서 장소(章疏)를 같이 올려 전조(前朝)의 왕씨(王氏)와 박위(朴葳)의 죄를 논핵(論劾)하니, 임금이 대궐 안에 머물러 두고 내려보내지 않으므로, 대궐 문에 엎드려 힘써 간(諫)했으나 임금이 윤허하지 아니하였다.
