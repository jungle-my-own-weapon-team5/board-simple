# 도승지 이직을 기복시키다

- 출전: 태조실록3권, 태조 2년 4월 2일 병자 2/3 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10204002_002
- URL: https://sillok.history.go.kr/id/kaa_10204002_002
- 분류: 인사-관리(管理)

## 국역

도승지(都承旨) 이직(李稷)을 기복(起復)시켰다. 처음에 이직이 아버지의 상사(喪事)를 당하여 경산부(京山府)에서 거상(居喪)하고 있었으므로, 임금이 강제로 그를 기복(起復)시킨 것이었다.
