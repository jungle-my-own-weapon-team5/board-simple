# 경기좌도와 충청도 각 고을에 지시하여 도성 보수를 시기에 맞추어 시행케 하다

- 출전: 태조실록14권, 태조 7년 5월 13일 기미 2/3 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10705013_002
- URL: https://sillok.history.go.kr/id/kaa_10705013_002
- 분류: 군사-관방(關防)

## 국역

경기좌도(京畿左道)와 충청도 주군(州郡)으로 하여금 시기에 맞추어 도성(都城)을 보완(補完)하게 하니, 성의 둘레가 9천 7백 60보(步)가 조금 넘었다.
