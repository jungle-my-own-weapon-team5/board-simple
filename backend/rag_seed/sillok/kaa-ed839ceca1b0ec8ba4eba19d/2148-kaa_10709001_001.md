# 해가 오색을 띠다. 낮과 밤에 성괴가 나타나다

- 출전: 태조실록15권, 태조 7년 9월 1일 계유 1/6 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10709001_001
- URL: https://sillok.history.go.kr/id/kaa_10709001_001
- 분류: 과학-천기(天氣)

## 국역

해가 오색을 띠었다. 금성(金星)이 낮에 나타나고, 밤에는 유성(流星)이 규성(奎星)·화성(火星)에서 나와 누성(婁星)의 분야로 들어갔다.
