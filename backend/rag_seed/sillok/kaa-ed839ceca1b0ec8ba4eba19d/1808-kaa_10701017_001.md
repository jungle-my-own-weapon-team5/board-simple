# 궁성 감독관의 장막이 연소되어 전 개성 윤 남성리가 죽다

- 출전: 태조실록13권, 태조 7년 1월 17일 을축 1/2 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10701017_001
- URL: https://sillok.history.go.kr/id/kaa_10701017_001
- 분류: 왕실-사급(賜給) / 군사-금화(禁火)

## 국역

궁성(宮城) 감독관(監督官)에게 술을 내려 주었다. 밤에 역부(役夫)가 불을 내어 북면(北面) 감독막(監督幕)이 연소(延燒)되었는데, 전 개성 윤(開城尹) 남성리(南成理)가 술에 취하여 나오지 못해서 죽었다.
