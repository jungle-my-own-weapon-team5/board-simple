# 사헌부에서 술 마신 흥복사 중 사근을 환속시키길 청하다

- 출전: 태조실록14권, 태조 7년 6월 3일 정미 3/5 기사 / 1398년 명 홍무(洪武) 31년

- URL: https://sillok.history.go.kr/id/kaa_10706003_003
- 분류: 사상-불교(佛敎) /

## 국역

흥복사(興福寺)의 중 사근(斯近)이 술을 마셨다가 일이 발각되니, 헌사(憲司)에서 도로 속인(俗人)이 되게 하여 군대에 편입하기를 청하였다.
