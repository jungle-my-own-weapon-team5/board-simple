# 개성부에서 다시 각 품의 집터를 정하다

- 출전: 태조실록7권, 태조 4년 1월 14일 기유 2/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10401014_002
- URL: https://sillok.history.go.kr/id/kaa_10401014_002
- 분류: 행정-지방행정(地方行政) / 주생활-택지(宅地)

## 국역

개성부에서 다시 각품(各品)의 집터를 정하였다. 정1품이 35부(負), 이하 한 품에 5부씩 내려 6품에 이르러 10부, 서민은 2부씩 주었다.
