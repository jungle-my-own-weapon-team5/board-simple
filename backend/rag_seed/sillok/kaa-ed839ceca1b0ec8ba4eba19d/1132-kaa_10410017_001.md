# 천둥 치고 샘물이 끓어 오른 것 때문에 내전에서 금경 법석을 행하다

- 출전: 태조실록8권, 태조 4년 10월 17일 정미 1/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10410017_001
- URL: https://sillok.history.go.kr/id/kaa_10410017_001
- 분류: 과학-천기(天氣) / 사상-불교(佛敎)

## 국역

임금이 겨울을 당하여 천둥과 샘물이 끓어올랐으므로, 금경 법석(金經法席)을 내전(內殿)에서 베풀고, 사람을 여러 절에 나누어 보내어 법석을 베풀게 하였다.
