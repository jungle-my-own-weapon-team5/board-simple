# 조회를 보고 나서 대사성 유경에게 《대학연의》를 강론하게 하다

## 국역

임금이 조회를 받는 예를 마치고 난 후에, 성균 대사성(成均大司成) 유경(劉敬)에게 명하여 《대학연의(大學衍義)》를 강론(講論)하게 하였다.
