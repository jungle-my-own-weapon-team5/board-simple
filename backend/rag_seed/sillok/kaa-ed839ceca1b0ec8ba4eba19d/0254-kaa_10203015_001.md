# 왜구에게 병선 3척을 빼앗긴 고만양 만호 신용무를 참형으로 논죄하다

- 출전: 태조실록3권, 태조 2년 3월 15일 경신 1/1 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10203015_001
- URL: https://sillok.history.go.kr/id/kaa_10203015_001
- 분류: 사법-행형(行刑) / 외교-왜(倭)

## 국역

도평의사사에서 형조의 정문(呈文)에 의거하여 아뢰었다.

"고만량 만호(高灣梁萬戶) 신용무(申用茂)가 왜구(倭寇)를 능히 방어하지 못하고 병선(兵船) 3척을 빼앗겼사오니, 율(律)에 의거하면 참형(斬刑)에 해당됩니다."

그대로 따랐다.
