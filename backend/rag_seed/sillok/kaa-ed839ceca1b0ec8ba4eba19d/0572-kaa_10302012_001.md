# 수창궁에 가다. 서소문의 옹성이 무너지려 하자 감역관을 옹진으로 귀양보내다

## 국역

임금이 수창궁에 거둥하였다. 서소문(西小門)의 옹성(甕城)013) 이 장차 기울어지려 한다는 이유로 감역관(監役官)을 옹진(甕津)의 수자리[戍]에 귀양보냈다.
