# 권중화 등이 《비록촬요》를 바치니 하윤·이직에게 진강케 하다

- 출전: 태조실록5권, 태조 3년 2월 16일 병술 1/1 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10302016_001
- URL: https://sillok.history.go.kr/id/kaa_10302016_001
- 분류: 왕실-행행(行幸) / 왕실-경연(經筵) / 출판-서책(書冊)

## 국역

임금이 수창궁에 거둥하였다. 영삼사사(領三司事) 권중화(權仲和) 등이 《비록촬요(秘錄撮要)》를 바치니, 임금이 하윤(河崙)과 이직(李稷)으로 하여금 진강(進講)하게 하였다.
