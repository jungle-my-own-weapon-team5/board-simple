# 일본에서 칼 20자루를 바치니 신하들에게 나누어 주고 시좌궁으로 돌아오다

## 국역

일본국에서 사신을 보내어 칼 20자루를 바치니, 임금이 대신들에게 내려 주고 시좌궁(時坐宮)으로 돌아왔다.
