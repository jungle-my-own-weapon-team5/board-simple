# 절비의 삼년상을 마치고 여러 왕자와 군에게 잔치를 베풀게 하다

- 출전: 태조실록4권, 태조 2년 11월 15일 병진 1/1 기사 / 1393년 명 홍무(洪武) 26년

- URL: https://sillok.history.go.kr/id/kaa_10211015_001

## 국역

세자(世子)에게 명하여 왕자(王子)와 여러 군(君)에게 잔치를 베풀게 하였으니, 절비(節妃)의 삼년상(三年喪)을 마친 때문이었다.
