# 통사 곽해룡이 예부의 자문 부본을 가지고 오니, 기뻐하여 말을 하사하다

- 출전: 태조실록3권, 태조 2년 2월 3일 무인 1/1 기사 / 1393년 명 홍무(洪武) 26년

- 분류: 왕실-사급(賜給) / 외교-명(明)

## 국역

주문사(奏聞使) 한상질(韓尙質)의 일행(一行)인 통사(通事) 곽해룡(郭海龍)이 예부(禮部)의 자문 부본(咨文副本)을 가지고 오니, 임금이 크게 기뻐하여 해룡(海龍)에게 말을 내려 주었다.
