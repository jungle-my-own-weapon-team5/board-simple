# 도성의 기초를 닦았으므로 백악과 오방 신에게 제사하다

- 출전: 태조실록9권, 태조 5년 1월 9일 무진 2/2 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10501009_002
- URL: https://sillok.history.go.kr/id/kaa_10501009_002
- 분류: 군사-관방(關防) / 사상-토속신앙(土俗信仰)

## 국역

도성(都城)의 기초를 열었으므로, 백악(白岳)과 5방(方)의 신(神)에게 치제(致祭)하였다.
