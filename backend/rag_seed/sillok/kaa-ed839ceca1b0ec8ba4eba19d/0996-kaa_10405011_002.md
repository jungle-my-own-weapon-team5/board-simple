# 처음으로 세자 부빈객을 두고 한상경과 유경을 좌우 부빈객으로 삼다

- 출전: 태조실록7권, 태조 4년 5월 11일 계묘 2/3 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10405011_002
- URL: https://sillok.history.go.kr/id/kaa_10405011_002
- 분류: 행정-중앙행정(中央行政) / 인사-임면(任免)

## 국역

처음으로 세자 부빈객(世子副賓客)을 두고 한상경(韓尙敬)으로 좌부빈객(左副賓客)을, 유경(劉敬)으로 우부빈객(右副賓客)을 삼았다.
