# 근정전에서 화엄삼매참 법석을 베풀었는데 108명의 중이 참가하고 너무 사치스러웠다

- 출전: 태조실록13권, 태조 7년 1월 7일 을묘 2/4 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10701007_002
- URL: https://sillok.history.go.kr/id/kaa_10701007_002
- 분류: 사상-불교(佛敎) / 재정-창고(倉庫)

## 국역

근정전(勤政殿)에 화엄삼매참 법석(華嚴三昧懺法席)을 베풀고 여러 창고(倉庫)에 명하여 공구(供具)를 베풀었는데, 사치가 너무 지나치게 심하였으니, 환자(宦者) 김사행(金師幸)의 한 짓이다. 회(會)에 참가한 중들이 1백 8명이었다.
