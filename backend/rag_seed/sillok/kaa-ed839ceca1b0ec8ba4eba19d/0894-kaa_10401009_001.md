# 여러 도에 특사를 보내어 군용을 검열하게 하다

- 출전: 태조실록7권, 태조 4년 1월 9일 갑진 1/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10401009_001
- URL: https://sillok.history.go.kr/id/kaa_10401009_001
- 분류: 군사-지방군(地方軍) / 인사-임면(任免)

## 국역

사신을 여러 도에 보내어 군용(軍容)을 점고(點考)하게 하였다. 상장군(上將軍) 신효창(申孝昌)을 경상도에, 대장군(大將軍) 김계수(金季壽)를 전라도에, 대장군 구성량(具成亮)을 풍해도(豐海道)에, 대장군 노상의(盧尙義)를 강릉도(江陵道)에 보냈다.
