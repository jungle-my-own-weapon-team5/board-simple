# 각도의 군사 2만을 징발, 기일을 엄수하여 서울에 올라와 성을 쌓게 하다

- 출전: 태조실록12권, 태조 6년 10월 29일 정미 3/3 기사 / 1397년 명 홍무(洪武) 30년
- 기사 ID: kaa_10610029_003
- URL: https://sillok.history.go.kr/id/kaa_10610029_003
- 분류: 군사-지방군(地方軍) / 군사-관방(關防)

## 국역

도당(都堂)에 명하여 각도의 군사 2만을 징발하여 기일을 엄수하여 서울에 올라와 성을 쌓되, 경상·전라도는 정월 20일까지, 충청·풍해도는 정월 15일까지로 하였다.
