# 정도전에게 새 궁궐의 침실 벽에 쓸 경계가 될 말을 모아 올리게 하다

- 출전: 태조실록8권, 태조 4년 9월 22일 계축 1/1 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10409022_001
- URL: https://sillok.history.go.kr/id/kaa_10409022_001
- 분류: 왕실-종사(宗社) /

## 국역

판삼사사 정도전(鄭道傳)에게 명하여 새 대궐의 침실(寢室) 사면의 벽 위에 본받을 만하고 경계될 만한 훈계를 쓰고자 하니, 경서와 사서에 있는 좋은 말들을 모아서 올리라고 하였다.
