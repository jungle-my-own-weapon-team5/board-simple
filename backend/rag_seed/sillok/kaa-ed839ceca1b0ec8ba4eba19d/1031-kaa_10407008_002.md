# 왜선 1척을 잡은 경상도 수군 첨절제사와 만호에게 궁온과 비단을 내리다

- 출전: 태조실록8권, 태조 4년 7월 8일 기해 2/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10407008_002
- URL: https://sillok.history.go.kr/id/kaa_10407008_002
- 분류: 외교-왜(倭) / 왕실-사급(賜給)

## 국역

경상도 수군 첨절제사 김천신(金天伸)과 만호 차준(車俊)이 왜선 1척을 잡았으므로, 조방현(趙方玄)을 보내어 각각 궁온(宮醞)과 비단을 하사하게 하였다.
