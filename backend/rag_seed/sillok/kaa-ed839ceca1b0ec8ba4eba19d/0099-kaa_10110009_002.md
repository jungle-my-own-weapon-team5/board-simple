# 유원정·박의중에게 관직을 제수하고, 자초를 왕사로 삼다

- 출전: 태조실록2권, 태조 1년 10월 9일 정사 2/6 기사 / 1392년 명 홍무(洪武) 25년
- 기사 ID: kaa_10110009_002
- URL: https://sillok.history.go.kr/id/kaa_10110009_002
- 분류: 인사-임면(任免) / 사상-불교(佛敎)

## 국역

유원정(柳爰廷)을 중추원 부사(中樞院副使)로 삼고, 박의중(朴宜中)을 예문춘추관 학사(藝文春秋館學士)로 삼고, 대성(臺省)의 낭관(郞官)을 모두 체천(遞遷)146) 하고, 중 자초(自超)147) 를 봉하여 왕사(王師)로 삼았다.
