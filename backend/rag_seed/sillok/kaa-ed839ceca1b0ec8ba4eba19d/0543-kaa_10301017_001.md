# 왕씨를 거제도로 이배시키고, 왕화·왕거를 안동옥에 가두다

- 출전: 태조실록5권, 태조 3년 1월 17일 정사 1/1 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10301017_001
- URL: https://sillok.history.go.kr/id/kaa_10301017_001
- 분류: 사법-행형(行刑) / 역사-전사(前史) /

## 국역

순군 진무(巡軍鎭撫) 김영화(金永和)와 천호(千戶) 유양(柳陽) 등을 보내어 왕씨(王氏)를 거제도(巨濟島)로 옮기게 하고, 또 대장군 심효생(沈孝生)을 보내어 왕화(王和)와 왕거(王琚)를 안동옥(安東獄)에 가두게 하였다.
