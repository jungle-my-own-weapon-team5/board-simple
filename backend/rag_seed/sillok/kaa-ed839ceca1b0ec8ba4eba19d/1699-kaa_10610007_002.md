# 남은을 충청도에 보내어 순성 옛 개천의 개통 편리 여부를 살피게 하다

- 출전: 태조실록12권, 태조 6년 10월 7일 을유 2/2 기사 / 1397년 명 홍무(洪武) 30년

- 분류: 인사-임면(任免) / 교통-수운(水運)

## 국역

의성군(宜城君) 남은(南誾)을 충청도에 보내어 순성(蓴城)의 예전 개천을 다시 개통하는 것의 편하고 편하지 않은 것을 살펴보게 하였다.
