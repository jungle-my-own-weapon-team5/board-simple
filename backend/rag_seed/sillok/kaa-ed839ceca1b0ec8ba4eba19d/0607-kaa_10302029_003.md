# 각도의 관찰사에게 수령의 치적을 보고토록 명하다

- 출전: 태조실록5권, 태조 3년 2월 29일 기해 3/5 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10302029_003
- URL: https://sillok.history.go.kr/id/kaa_10302029_003

## 국역

도평의사사에 명하여 각도의 관찰사에게 공문을 보내어 임인년 이래의 주군(州郡) 수령(守令)의 정적(政績)을 조사하여 아뢰게 하였다.
