# 오도리 10명이 토산물을 바치다

- 출전: 태조실록7권, 태조 4년 2월 7일 신미 1/1 기사 / 1395년 명 홍무(洪武) 28년

## 국역

오도리(吾都里) 10인이 와서 토산물을 바쳤으므로, 쌀과 베[布]를 주어서 후하게 위무(慰撫)하였다.
