# 태종이 정릉 등이 있는 산의 형세를 그린 그림을 바치고, 각 능마다 능직과 수릉호를 두다

## 국역

지금의 전하(殿下)166) 가 〈함길도에서〉 와서 여러 능(陵)의 산세(山勢)를 그린 화본(畫本)을 바쳤다. 정릉(定陵)167) ·화릉(和陵)168) ·의릉(義陵)169) ·순릉(純陵)170) 은 모두 함주(咸州)171) 에 있고, 지릉(智陵)172) 은 안변(安邊)에 있고, 숙릉(淑陵)173) 은 문주(文州)174) 에 있고, 덕릉(德陵)175) ·안릉(安陵)176) 은 공주(孔州)177) 에 있는데, 능(陵)마다 능지기[陵直] 권무(權務) 2인과 수릉호(守陵戶)178) 몇 호(戶)를 두고 재궁(齋宮)을 건축해 세웠다.
