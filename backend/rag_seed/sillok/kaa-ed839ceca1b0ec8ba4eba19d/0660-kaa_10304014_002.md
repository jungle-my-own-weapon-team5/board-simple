# 왜선 1척을 섬멸한 경상도 수군 첨절제사 안처선에게 물품을 하사하다

- 출전: 태조실록5권, 태조 3년 4월 14일 계미 2/3 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10304014_002
- URL: https://sillok.history.go.kr/id/kaa_10304014_002
- 분류: 외교-왜(倭) / 왕실-사급(賜給)

## 국역

경상도 수군 첨절제사 안처선(安處善)이 왜적의 배 1척을 잡으니, 사자(使者)를 보내어 궁온(宮醞)과 무늬 있는 비단과 명주를 내려 주었다.
