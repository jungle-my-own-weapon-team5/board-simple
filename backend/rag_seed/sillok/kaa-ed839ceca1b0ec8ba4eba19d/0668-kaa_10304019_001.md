# 역대 부국 강병의 방법과 임적 응변의 계책을 상고하여 보고토록 하다

## 국역

예문관·성균관·교서감(校書監)에 명하여 역대(歷代) 경사(經史)에 기재된 부국 강병(富國强兵)의 방법과 임적 응변(臨敵應變)의 계책을 상고하여 써서 아뢰게 하였다.
