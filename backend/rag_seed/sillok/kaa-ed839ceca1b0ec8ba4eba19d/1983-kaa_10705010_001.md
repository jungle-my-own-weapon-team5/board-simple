# 《대장경》 목판을 강화 선원사에서 운반하여 왔으므로 임금이 용산강에 거둥하다

- 출전: 태조실록14권, 태조 7년 5월 10일 병진 1/1 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10705010_001
- URL: https://sillok.history.go.kr/id/kaa_10705010_001
- 분류: 왕실-행행(行幸) / 사상-불교(佛敎)

## 국역

임금이 용산강(龍山江)에 거둥하였다. 《대장경(大藏經)》의 목판(木版)을 강화(江華)의 선원사(禪源寺)로부터 운반하였다.
