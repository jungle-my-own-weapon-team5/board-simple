# 송사 판결문에 세자의 이름을 쓴 형조 장무 정랑 김온을 순군옥에 가두다

- 출전: 태조실록9권, 태조 5년 1월 3일 임술 1/1 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10501003_001
- URL: https://sillok.history.go.kr/id/kaa_10501003_001

## 국역

형조(刑曹)의 장무(掌務)인 정랑(正郞) 김온(金穩)을 순군옥(巡軍獄)에 가두었으니, 송사를 판결하는 계본에 세자의 이름[諱]을 써 놓았기 때문이었다.
