# 판봉상시사 김을상이 진헌마 오백필을 요동에서 교부하고 돌아오다

- 출전: 태조실록6권, 태조 3년 6월 16일 갑신 2/2 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10306016_002
- URL: https://sillok.history.go.kr/id/kaa_10306016_002
- 분류: 외교-명(明) /

## 국역

최연(崔淵)이 전한 선유(宣諭)로 판봉상시사(判奉常寺事) 김을상(金乙祥)을 보내서 진헌마(進獻馬) 5백 필을 요동까지 끌고 가 교할하고 돌아오게 하였다.
