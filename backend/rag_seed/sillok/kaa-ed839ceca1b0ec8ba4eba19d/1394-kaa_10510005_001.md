# 아일조회는 5경 4점, 대조회는 5경 1점에 궐문에 모이게 하다

- 출전: 태조실록10권, 태조 5년 10월 5일 기축 1/1 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10510005_001
- URL: https://sillok.history.go.kr/id/kaa_10510005_001
- 분류: 왕실-의식(儀式)

## 국역

백관(百官)에게 명하여 아일 조회(衙日朝會)는 5경(更) 4점(點)에, 대조회(大朝會)는 5경 1점에 다 궐문(闕門)에 모이게 하였다.
