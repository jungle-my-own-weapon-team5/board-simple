# 유구국 사신과 오량합의 사람이 조회에 참여하다

- 출전: 태조실록2권, 태조 1년 9월 11일 기축 1/2 기사 / 1392년 명 홍무(洪武) 25년
- 기사 ID: kaa_10109011_001
- URL: https://sillok.history.go.kr/id/kaa_10109011_001
- 분류: 외교-유구(琉球) / 외교-야(野)

## 국역

임금이 조회를 보았다. 유구국(琉球國)의 사신과 오량합(吾良哈)092) 의 사람들이 조회에 참예하였다. 유구국의 사신은 동반(東班) 5품의 아래에 자리를 잡았고, 오량합은 서반(西班) 4품의 아래에 자리를 잡았고, 그 종자(從者)들은 6품의 아래에 자리를 잡았다. 유구국에서 방물(方物)을 바치었다.
