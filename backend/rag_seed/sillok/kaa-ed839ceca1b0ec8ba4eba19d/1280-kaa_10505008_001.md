# 도성 축조 역사의 감독을 소홀히 한 판중추원사 이빈이 탄핵당하다

- 출전: 태조실록9권, 태조 5년 5월 8일 갑자 1/1 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10505008_001
- URL: https://sillok.history.go.kr/id/kaa_10505008_001
- 분류: 행정-중앙행정(中央行政) / 사법-행형(行刑) / 군사-관방(關防)

## 국역

간관(諫官)이 판중추원사 이빈(李彬)을 탄핵하였다. 이빈은 축성 제조(築城提調)로 있으면서 여러 차례 사제(私第)에 돌아갔다 왔으므로 역사를 감독하는 데 소홀히 하였었다. 임금이 그의 직첩을 거두도록 명하고 전민(田民)을 몰수해 들이고는 영해부(寧海府)로 귀양보냈다.
