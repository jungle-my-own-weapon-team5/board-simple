# 특명으로 상장군 노석주를 겸 상서 소윤에 임명하다

- 출전: 태조실록8권, 태조 4년 10월 7일 정유 1/2 기사 / 1395년 명 홍무(洪武) 28년
- 기사 ID: kaa_10410007_001
- URL: https://sillok.history.go.kr/id/kaa_10410007_001
- 분류: 인사-임면(任免) / 인사-선발(選拔)

## 국역

상장군 노석주(盧石柱)로 겸 상서 소윤(兼尙瑞少尹)을 삼았다. 석주는 과거에 급제하여 벼슬한 자는 아니고, 왕의 특지(特旨)로 나왔었다.
