# 경비의 기일이므로 조회를 정지하고, 광명사에서 중 5백명을 공양하다

- 출전: 태조실록4권, 태조 2년 7월 23일 병인 1/1 기사 / 1393년 명 홍무(洪武) 26년

## 국역

황조비(皇祖妣) 경비(敬妃)의 기신(忌辰)이므로 조회를 정지하고, 중 5백 명을 광명사(廣明寺)에서 공양(供養)하였다.
