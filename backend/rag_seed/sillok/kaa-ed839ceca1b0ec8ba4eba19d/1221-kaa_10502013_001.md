# 왜선 1척을 잡은 풍해도 도관찰사 송문중에게 궁온과 비단을 하사하다

- 출전: 태조실록9권, 태조 5년 2월 13일 신축 1/2 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10502013_001
- URL: https://sillok.history.go.kr/id/kaa_10502013_001
- 분류: 외교-왜(倭) / 왕실-사급(賜給)

## 국역

풍해도 도관찰사 송문중(宋文中)이 왜선 1척을 잡아서 수급(首級)을 바치니, 대장군 김점(金漸)을 보내어 궁온(宮醞)과 비단을 하사하였다.
