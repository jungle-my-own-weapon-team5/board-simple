# 각도에 명하여 창고의 쌀과 콩을 나누어 주고 보리로 바치게 하다

- 출전: 태조실록14권, 태조 7년 윤5월 14일 기축 1/1 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10705114_001
- URL: https://sillok.history.go.kr/id/kaa_10705114_001
- 분류: 재정-창고(倉庫) / 농업-권농(勸農)

## 국역

각도에 명령하여 창고의 쌀과 콩을 내어 백성에게 나누어 주고 보리를 바꾸어 바치게 하였으니, 장차 백성에게 주어서 종자로 하게 함이었다.
