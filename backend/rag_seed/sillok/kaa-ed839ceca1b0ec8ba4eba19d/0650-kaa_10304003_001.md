# 척석군을 사열하고 조기에게 거느리게 하다

- 출전: 태조실록5권, 태조 3년 4월 3일 임신 1/3 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10304003_001
- URL: https://sillok.history.go.kr/id/kaa_10304003_001
- 분류: 풍속-풍속(風俗) / 인사-임면(任免) /

## 국역

임금이 동량청(東涼廳)에 앉아 척석군(擲石軍)을 불러 사열하고, 중추(中樞) 조기(趙琦)에게 명하여 이들을 거느리게 하였다.
