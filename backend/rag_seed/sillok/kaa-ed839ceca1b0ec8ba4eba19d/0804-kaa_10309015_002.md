# 성변(星變) 때문에 죄수를 용서하고 재상들에게 정사의 잘잘못을 말하게 하다

- 출전: 태조실록6권, 태조 3년 9월 15일 임자 2/2 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10309015_002
- URL: https://sillok.history.go.kr/id/kaa_10309015_002
- 분류: 과학-천기(天氣) / 사법-행형(行刑) /

## 국역

성변(星變)으로 인하여 이죄(二罪) 이하의 죄수를 용서하고, 재상들로 하여금 각각 현재 행하고 있는 정치의 잘하고 못하는 것과 백성들의 이롭고 해되는 것을 말하게 하였다.
