# 울주 지주사 이은이 왜구 6급을 베니 비단을 내려 주다

- 출전: 태조실록10권, 태조 5년 11월 17일 신미 2/2 기사 / 1396년 명 홍무(洪武) 29년
- 기사 ID: kaa_10511017_002
- URL: https://sillok.history.go.kr/id/kaa_10511017_002
- 분류: 외교-왜(倭) / 왕실-사급(賜給)

## 국역

왜구가 울주(蔚州) 지방을 침략하니 지주사(知州事) 이은(李殷)이 주병(州兵)을 독려해서 왜구 6급(級)을 베었으므로, 비단을 내려 주었다.
