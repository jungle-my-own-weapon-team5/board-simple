# 유구·정신의·이직·함부림·조서·정구·허주에게 관직을 제수하다

- 출전: 태조실록11권, 태조 6년 1월 28일 신사 2/4 기사 / 1397년 명 홍무(洪武) 30년
- 기사 ID: kaa_10601028_002
- URL: https://sillok.history.go.kr/id/kaa_10601028_002
- 분류: 인사-임면(任免)

## 국역

유구(柳玽)로 삼사 우복야(三司右僕射)를, 정신의(鄭臣義)로 지중추부사(知中樞府事)를, 이직(李稷)으로 대사헌을, 함부림(咸傅霖)으로 좌산기(左散騎)를, 조서(曺庶)로 우산기(右散騎)를, 정구(鄭矩)로 좌간의(左諫議)를, 허주(許周)로 사헌 중승(司憲中丞)을 삼았다.
