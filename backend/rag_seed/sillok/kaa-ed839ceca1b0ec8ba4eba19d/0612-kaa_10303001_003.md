# 예조에서 동경과 서경의 구정과 초례를 혁파하고 개경에만 남겨두기를 청하니 윤허하다

- 출전: 태조실록5권, 태조 3년 3월 1일 경자 3/4 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10303001_003
- URL: https://sillok.history.go.kr/id/kaa_10303001_003

## 국역

예조에서 장계(狀啓)하였다.

"전조(前朝)의 태조(太祖)가 삼경(三京)035) 에 순행하여 거주했던 까닭으로, 동경(東京)036) 과 서경(西京)037) 에 모두 구정(毬庭)과 초례(醮禮)038) 를 설치했는데, 지금 정치를 혁신(革新)하는 초기에 마땅히 그전의 폐단을 그대로 따를 수는 없사오니, 청하옵건대, 동경과 서경에는 없애버리고 다만 본경(本京)039) 에만 시행하게 하소서."

그대로 따랐다.
