# 동지이므로 황제를 향해 하례하고, 여러 신하들의 하례는 정지시키다

- 출전: 태조실록4권, 태조 2년 11월 10일 신해 1/1 기사 / 1393년 명 홍무(洪武) 26년

- URL: https://sillok.history.go.kr/id/kaa_10211010_001

## 국역

동지(冬至)이므로 임금이 여러 신하를 거느리고 황제의 궁궐을 향하여 하례(賀禮)를 행하고, 여러 신하들의 하례는 정지하게 하였다.
