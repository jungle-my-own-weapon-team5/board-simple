# 계룡산에서 돌아오니 백관이 맞이하고, 채붕과 나례를 설치하다

- 출전: 태조실록3권, 태조 2년 2월 27일 임인 1/2 기사 / 1393년 명 홍무(洪武) 26년
- 기사 ID: kaa_10202027_001
- URL: https://sillok.history.go.kr/id/kaa_10202027_001
- 분류: 왕실-행행(行幸) / 왕실-의식(儀式)

## 국역

임금이 계룡산으로부터 이르니, 백관(百官)들이 용둔(龍屯) 들에서 맞이하였다. 임금이 숭인문(崇仁門)으로 들어오니 채붕(綵棚)과 나례(儺禮)를 시좌궁(時座宮) 문밖에 설치하였다. 성균관의 학관(學官)이 여러 유생(儒生)을 거느리고 가요(歌謠)를 불러 올렸다.
