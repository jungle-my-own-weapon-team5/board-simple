# 지울주사 이은을 대마도까지 따라가 살려낸 아전 2사람의 향역을 면제하다

- 출전: 태조실록13권, 태조 7년 1월 26일 갑술 2/3 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10701026_002
- URL: https://sillok.history.go.kr/id/kaa_10701026_002
- 분류: 재정-역(役) / 외교-왜(倭)

## 국역

울주(蔚州)의 아전 이도(李陶)·박언(朴焉)의 향역(鄕役)을 면제하였다. 처음에 왜적이 지울주사(知蔚州事) 이은(李殷)을 잡아가매, 도(陶)와 언(焉)이 따라가서 대마도(對馬島)에 이르러 살려내었었다. 경상도 도관찰사(都觀察使) 이지(李至)가 진달하여 청하니 윤허하였다.
