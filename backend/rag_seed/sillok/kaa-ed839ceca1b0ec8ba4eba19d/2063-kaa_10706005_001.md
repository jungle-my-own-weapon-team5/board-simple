# 김승·정진·김희선에게 관직을 제수하다

- 출전: 태조실록14권, 태조 7년 6월 5일 기유 1/4 기사 / 1398년 명 홍무(洪武) 31년
- 기사 ID: kaa_10706005_001
- URL: https://sillok.history.go.kr/id/kaa_10706005_001
- 분류: 인사-임면(任免)

## 국역

김승(金陞)을 동지중추원사(同知中樞院事)로, 정진(鄭津)을 중추원부사(中樞院副使)로 삼았다. 정진은 정도전의 아들이다. 김희선(金希善)을 원주 목사(原州牧使)로 삼았다.
