# 한양으로 서울을 옮기다

- 출전: 태조실록6권, 태조 3년 10월 25일 신묘 1/1 기사 / 1394년 명 홍무(洪武) 27년
- 기사 ID: kaa_10310025_001
- URL: https://sillok.history.go.kr/id/kaa_10310025_001
- 분류: 왕실-행행(行幸) / 인사-임면(任免)

## 국역

한양으로 서울을 옮기었다. 각 관청의 관원 2명씩은 송경에 머물러 있게 하고, 문하 시랑찬성사 최영지(崔永沚)와 상의문하부사 우인열(禹仁烈) 등으로 분도평의사사(分都評議使司)를 삼았다.
