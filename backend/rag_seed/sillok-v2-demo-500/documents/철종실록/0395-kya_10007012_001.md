# 공제가 끝난 이튿날이어서 시·원임 대신과 각신이 문안을 드리다

약원(藥院)013) 에서 희정당(熙政堂)에 입진(入診)하였다. 시·원임 대신과 각신(閣臣)을 소견하였으니, 공제(公除)가 끝난 이튿날이기에 문안을 드린 것이다.
