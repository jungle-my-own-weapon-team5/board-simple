# 김난순·윤의검을 수원부 유수·우변 포도 대장으로 삼다

김난순(金蘭淳)을 수원부 유수(水原府留守)로, 윤의검(尹義儉)을 우변 포도 대장(右邊捕盜大將)으로 삼았다.
