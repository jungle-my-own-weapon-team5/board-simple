# 상장의 일은 과거에 정승 이상을 지낸 자와 의논하여 행하게 하다

예조(禮曹)에 전교하기를,

"상장(喪葬)의 모든 일은 밀성군(密城君) 이침(李琛)·영순군(永順君) 이부(李溥)와 일찍이 정승 이상을 지낸 자와 같이 의논하여 행하라."

하였다.
