# 대왕 대비가 두 대비전·중궁·수빈궁에 바치는 납촉을 졸곡까지 없애라고 명하다

대왕 대비가 전교(傳敎)하기를,

"나와 왕대비(王大妃) 그리고 중궁(中宮)·수빈궁(粹嬪宮)에 공진(供進)하는 납촉(蠟燭)은 졸곡(卒哭)까지만 한정하여 이를 없애게 하라."

하였다.
