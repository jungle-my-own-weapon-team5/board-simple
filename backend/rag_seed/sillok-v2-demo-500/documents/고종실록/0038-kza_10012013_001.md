# 등극하는 의식을 거행하고 왕비를 왕대비로 올리는 의식도 거행하다

성복(成服)하였다. 왕위를 이은 임금이 빈전(殯殿)에 나아가 대보(大寶)를 받고 인정문(仁政門)에 이르러 즉위하는 예를 행하였다. 왕비(王妃)를 높여 대비(大妃)로 하였다. 대왕대비(大王大妃)를 받들고 희정당(熙政堂)에서 수렴동청정(垂簾同聽政) 예를 행하였다.
