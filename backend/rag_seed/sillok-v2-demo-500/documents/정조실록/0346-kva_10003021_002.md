# 김양택·채제공·김종정·이휘지·김한기를 각 도감 제조로 삼다

김양택(金陽澤)을 총호사 겸 추숭 상시 봉릉 봉원 도감 도제조(摠護使兼追崇上諡封陵封園都監都提調)로 삼았다. 이때 김약행(金若行)이 김상철(金尙喆)을 논박한 상소를 유중(留中)하여 계하(啓下)하지 않았으므로, 김상철이 총호사의 직임을 사면하게 된 것이었다. 채제공(蔡濟恭)·김종정(金鍾正)·이휘지(李徽之)를 국장 도감 제조로, 김한기(金漢耆)를 빈전 도감 제조로 삼았다.
