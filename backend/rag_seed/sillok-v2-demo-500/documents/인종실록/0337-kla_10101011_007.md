# 구수담·이윤경·곽순 등에게 관직을 제수하다

구수담(具壽聃)을 승정원 동부승지로, 이윤경(李潤慶)을 사간원 대사간으로, 곽순(郭珣)을 사간으로, 민전(閔荃)을 장령으로, 심봉원(沈逢源)을 헌납으로, 노수신(盧守愼)을 정언으로 삼았다.
