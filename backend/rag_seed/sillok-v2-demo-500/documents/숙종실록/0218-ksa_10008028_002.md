# 숙종실록: 결원이 있는 양사의 관직을 임시로 제수하다

- 분류: 인사-임면(任免)

## 국역

# 결원이 있는 양사의 관직을 임시로 제수하다

이때 양사(兩司)의 관직에 결원이 많았는데, 명하여 공제(公除)049) 후에는 개정(開政)050) 하게 하되, 많은 관직을 오랫동안 비워둘 수는 없으므로 임시 변통으로 구전(口傳)으로 차출(差出)하도록 하여, 이익상(李翊相)을 대사간(大司諫)으로, 이헌(李藼)을 사간(司諫)으로, 김만중(金萬重)을 헌납(獻納)으로, 이우정(李宇鼎)을 정언(正言)으로, 민시중(閔蓍重)을 대사헌(大司憲)으로, 이하진(李夏鎭)을 집의(執義)로, 조이병(趙爾炳)을 장령(掌令)으로, 조종저(趙宗著)와 윤지완(尹趾完)을 지평(持平)으로 삼았다.
