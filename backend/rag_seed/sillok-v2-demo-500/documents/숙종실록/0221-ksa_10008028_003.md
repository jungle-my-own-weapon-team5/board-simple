# 숙종실록: 총호사가 각 아문과 각영의 미포와 은자를 모군의 부역 대가로 줄 것을 아뢰니 허락하다

- 기사 ID: ksa_10008028_003
- URL: https://sillok.history.go.kr/id/ksa_10008028_003
- 날짜: 숙종실록1권, 숙종 즉위년 8월 28일 기미 3/3 기사 / 1674년 청 강희(康熙) 13년
- 분류: 재정-국용(國用), 재정-역(役), 군사-병참(兵站)

## 국역

# 총호사가 각 아문과 각영의 미포와 은자를 모군의 부역 대가로 줄 것을 아뢰니 허락하다

총호사(摠護使)가 각 아문과 각영(各營)의 미포(米布)와 은자(銀子)를 거두어 모군(募軍)의 부역 대가로 줄 것을 청하니 허락하였다.
