# 광해군정초본: 정원이 총호사·빈전 도감 당상과 예관으로 하여금 직접 집사하게 하라고 아뢰다

## 국역

# 정원이 총호사·빈전 도감 당상과 예관으로 하여금 직접 집사하게 하라고 아뢰다

정원이 아뢰기를, "더없이 중차대한 일을 단지 내관에게만 하게 하는 것은 미안할 것 같습니다. 총호사, 빈전 도감 당상과 예관으로 하여금 직접 집사하게 하소서."

하니, 전교하기를,

"자전께 품하였더니 하교 내용이 ‘더없이 중대한 일을 대신이 직접 집사하려 하는 것은 당연한 일이다. 그러나 대내(大內)에서의 거둥이 있으니, 어떻게 해야 하겠는가?’ 하였다."

하였다.
