# 연산군일기: 예조가 태종 대왕의 칭호를 임시로 칭하고, 홍문관이 옛 제도를 상고하도록 아뢰다

- 분류: 왕실-종사(宗社)

## 국역

# 예조가 태종 대왕의 칭호를 임시로 칭하고, 홍문관이 옛 제도를 상고하도록 아뢰다

예조(禮曹)가 아뢰기를,

"태종 대왕은 세대(世代)의 순서가 조천(祧遷)해야 할 것인데, 종묘(宗廟)에 계신 동안은 칭호(稱號)가 난처하오니, 지금 우선 그저 태종이라고 칭하고 뒤에 홍문관으로 하여금 옛 제도를 상고하여 시행하게 하소서."

하니, 정승에게 보이게 하매, 정승들이 아뢰기를,

"마땅히 예조가 아뢴 대로 해야 합니다."

하니, 그대로 좇았다.
