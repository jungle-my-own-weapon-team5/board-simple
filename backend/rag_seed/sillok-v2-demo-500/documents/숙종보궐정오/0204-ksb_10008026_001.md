# 인화문에서 청 사신을 접견하다

임금이 청(淸)나라 사신(使臣)을 인화문(仁和門) 안에서 접견(接見)하였다. 청나라 사신이 나와서 우리 나라 사람에게 말하기를,

"너희 주상(主上)은 자라면 반드시 엄명(嚴明)할 것이다. 너희 나라 신하들은 마땅히 근신(謹愼)해야 할 것이다."

하였다.
