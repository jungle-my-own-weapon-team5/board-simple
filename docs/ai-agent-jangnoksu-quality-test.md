# AI Agent 품질 테스트: 장녹수 일화 게시글 생성

- 테스트 일시: 2026-06-18
- 대상 API: `POST /api/ai/editor-agent/run`
- 목적: "장녹수에 대해 그녀의 일화와 관련 기록을 찾아 게시물 본문을 채워달라"는 요청에서 Agent가 적절한 근거 검색, 외부 검색, 본문 생성을 수행하는지 확인

## 테스트 입력

```json
{
  "title": "장녹수의 일화는 어떻게 기록되었을까?",
  "content": "",
  "post_type": "토론",
  "category": "인물 열전",
  "message": "장녹수에 대해서 집필하려고 해. 그녀의 일화와 관련 기록을 찾아서 게시물 본문을 900자 정도로 채워줘. 사실과 후대 이미지가 섞이는 부분은 구분해서 써줘.",
  "history": []
}
```

## Editor Agent 실행 로그

```text
intent: 사용자 메시지를 `본문 생성` 요청으로 분류했습니다.
rag.search: 관련 내부 RAG 근거 3건을 조회했습니다. 근거: 세종의 식생활과 건강, 태종실록: 세자가 금빛 고양이를 구하려 하다
external.search: 내부 RAG 근거가 충분해 외부 검색을 건너뛰었습니다.
respond: LangGraph 노드 흐름으로 응답을 생성했습니다.
```

## 생성 결과 요약

- action: `fill_content`
- weak_evidence: `false`
- external_resources: `[]`
- suggested_title: `장녹수의 일화는 어떻게 기록되었을까?`
- suggested_content 품질: 실패

문제 문장 예시:

```text
내부 RAG에서 확인한 근거를 함께 보면, ... 세종의 식생활과 건강, 태종실록: 세자가 금빛 고양이를 구하려 하다 ...
```

생성 본문은 장녹수의 실제 일화나 연산군 관련 기록을 거의 다루지 못했고, 사용자 요청 문장을 본문 안에 재사용했다. 또한 제목 뒤에 조사 처리가 깨져 `장녹수의 일화는 어떻게 기록되었을까?은` 같은 문장이 생성되었다.

## RAG 단독 검색 결과

같은 Agent용 query로 RAG를 직접 호출한 결과:

```text
1. 세종의 식생활과 건강 · relevance 1.0
2. 태종실록: 세자가 금빛 고양이를 구하려 하다 · relevance 0.9
3. 고종실록: 수렴하는 것과 관련하여 반포문을 내리다 · relevance 0.8
weak_evidence: false
```

핵심어 중심 query인 `장녹수 일화 연산군 기록`으로 다시 검색해도 다음처럼 직접 근거가 아닌 결과가 충분 근거로 판정되었다.

```text
1. 사림 · relevance 0.7
2. 과거 · relevance 0.7
weak_evidence: false
```

판정: RAG 품질 실패. 현재 관련도 점수와 weak_evidence 판정이 query의 핵심 고유명사 일치 여부를 충분히 반영하지 못한다.

## 외부 검색 단독 결과

`장녹수` 외부 검색은 관련 후보를 찾았다.

```text
1. 「장녹수」 (도봉) · 네이버 검색/encyc
   - KBS 드라마 항목이라 직접 사료 근거로는 부적합
2. 장녹수 · 네이버 검색/encyc
   - 가난, 여러 혼인, 연산군과의 관계 등 인물 서술 후보
3. 장녹수 · 네이버 검색/encyc
   - 조선 중기 연산군의 총희. 제안대군 가비, 가무 등 핵심 설명 포함
4. 장녹수 · 네이버 검색/encyc
   - 한문 원문 성격의 자료 후보
5. 희빈 장씨와 장녹수 · 네이버 검색/encyc
   - 비교/대중 서술 후보
```

판정: 외부 검색은 보강 가능성이 있었다. 그러나 Agent가 내부 RAG를 충분하다고 판단해 외부 검색을 건너뛰면서 활용되지 못했다.

## 품질 판정

- 근거 적합성: 실패
- 외부 검색 활용: 실패
- 본문 완성도: 실패
- 사용자 요구 반영: 실패
- 로그 투명성: 부분 성공

## 원인

1. RAG 검색 결과가 핵심 인물 `장녹수`를 포함하지 않아도 높은 relevance를 받는다.
2. `_usable_citations`가 relevance cutoff만 보고 고유명사 불일치를 걸러내지 않는다.
3. `fill_content` 요청에서 RAG가 충분하다고 판정되면 외부 검색을 건너뛴다.
4. fallback/local content 생성기가 실제 근거 대신 사용자 요청문과 RAG 요약을 본문에 그대로 섞는다.
5. 외부 검색 결과도 드라마/대중 콘텐츠와 인물 백과 항목을 더 엄격히 구분해야 한다.

## 개선 제안

1. RAG citation 품질 판정에 핵심 엔티티 포함 여부를 추가한다.
   - query에서 `장녹수`, `연산군` 같은 고유명사를 추출한다.
   - citation title/summary/source metadata에 핵심 엔티티가 없으면 relevance가 높아도 weak 처리한다.
2. `fill_content`에서 인물/일화/기록 요청은 외부 검색을 강제 보강한다.
   - 특히 `일화`, `기록`, `찾아서`, `관련 기록`, `사료`가 있으면 내부 RAG가 애매할 때 외부 검색을 건너뛰지 않는다.
3. 외부 검색 랭킹에서 드라마/작품 항목을 인물 백과 항목보다 낮춘다.
4. suggested_content 생성 시 약한 RAG 제목을 본문 근거처럼 넣지 않는다.
5. 테스트 케이스로 `장녹수`, `어우동`, `정미수`, `양녕대군`을 묶어 회귀 테스트를 만든다.
